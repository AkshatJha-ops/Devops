# Exercise 7: Jenkins CI/CD Pipeline

## Objective
Create a Jenkins Declarative Pipeline with Checkout, Build, Test, and Deploy stages.

## Tools Used
- Jenkins
- Docker Desktop
- PowerShell
- Git and GitHub

## Pipeline Stages
1. Checkout — starts the pipeline.
2. Build — prints a successful build message.
3. Test — prints a successful test message.
4. Deploy — prints a successful deployment message.

## Verification
Run the Jenkins pipeline and check the console output for all four stages and `Finished: SUCCESS`.

## Result
The pipeline demonstrates the flow of a basic CI/CD pipeline. The Build, Test, and Deploy stages currently print messages rather than building or deploying a real application.
